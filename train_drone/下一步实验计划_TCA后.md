# 下一步实验计划：TCA_P3 后续路线

> **历史文档警告（2026-10-16）**：本文件记录 2026-08-24 时的计划，已被最新科研路线替代。TCA_P3P4 后续实验已显示负收益，不再执行下方“优先级 1”和“下一次训练建议”。当前下一步应先做门控、o2o/o2m、Tile 数据和导出诊断，再筛选“监督式共享小目标先验 + 尺度适配器（STP-SCA）”。最新决策见 `train_drone/当前创新优先级_2026-10-16.md`、`train_drone/docs/YOLO小目标改进点记忆文档.md` 与项目根目录 `研究重启_2026-09-25/00_科研重启总路线.md`。

## 当前结论

当前最优轻量化候选：

```text
YOLO26 + P2 + FGDDown + DySample + TGPFuse3 + P5SPFPrune + TCA_P3
```

最优结果：

```text
mAP50      = 0.43982
mAP50-95   = 0.26568
Params     = 2.037372M
```

这个模型的优势是参数量低，精度略高于前面的 TGPFuse3 与 P5SPFPrune。缺点是提升幅度仍然不够大，说明继续只在单点加轻量注意力，收益已经偏小。

## 优先级 1：TCA_P3P4

### 目的

在 P3 加 TCA 已经有小幅正收益，因此下一步做单变量扩展：同时在 P3 和 P4 两个检测特征处加入轻量卷积注意力。

### 为什么先试 P4

P5SPFPrune 删除了原始 P5 检测头，但用 P5SPF 把 P5 语义注入到 P4。因此 P4 是当前模型中“最高语义检测层”，对车辆、公交车、卡车等稍大目标以及复杂背景抑制有影响。

### 预期

```text
目标 mAP50      >= 0.442
目标 mAP50-95   >= 0.267
参数量           约 2.05M 左右
```

如果该实验没有明显提升，说明 TCA 不适合继续扩展，应停止堆注意力。

## 优先级 2：P5Prune_NoSPF 消融

### 目的

证明 P5SPF 不是“简单删 P5 检测头”的效果，而是真的发挥了高层语义保留作用。

### 实验设计

在当前 P5SPFPrune 路线中：

```text
删除 P5 Detect
不加入 P5SPF
Detect 仍使用 P2/P3/P4
```

### 预期

如果 P5Prune_NoSPF 明显低于 P5SPFPrune，就能说明 P5SPF 是有效创新模块。

## 优先级 3：暂缓 Loss 改进

CS-SlideLoss 实验已经下降：

```text
best mAP50    = 0.42793
best mAP50-95 = 0.26075
```

暂时不要继续把 loss 作为主线。它可以以后作为附加讨论或失败实验，不建议再消耗显卡时间。

## 当前论文创新点组织

可以暂时按三个 Neck 创新点组织：

```text
1. FGDDown：小目标细节保持下采样
2. TGPFuse：门控式跨尺度特征融合，替代简单 Concat
3. P5SPFPrune：高层语义保留式 P5 检测头剪枝
```

TCA_P3 暂定为辅助增强模块。如果 TCA_P3P4 有明显提升，则可升级为第四个创新点；如果提升不明显，则作为轻量注意力补充消融。

## 下一次训练建议

先跑：

```text
YOLO26 + P2 + FGDDown + DySample + TGPFuse3 + P5SPFPrune + TCA_P3P4
```

训练设置建议：

```text
imgsz=960
epochs=150 或 200
batch=8 或按显存调整
workers=8
amp=True
close_mosaic=10
```

如果 120 轮以后 mAP50-95 连续 20 轮没有刷新，可以提前停止。
