## P3 STP-SCA 快速筛选（5×100ep，单 seed）

### 任务

基于 P5SPFPrune（无 TCA）重跑作为 A0，其余同预算：

| 组别 | 设计                                                 | 回答的问题           |
| ---- | ---------------------------------------------------- | -------------------- |
| A0   | 原 P5SPFPrune 重跑 100ep                             | 结构基准             |
| A1   | +监督 prior 但不门控（辅助 loss）                    | 收益是否只是辅助训练 |
| A2   | 各位置独立受监督 prior                               | 共享是否必要         |
| A4   | 共享不监督 prior + 适配器（与 A5 同图，loss 权重=0） | 监督是否必要         |
| A5   | 完整 STP-SCA                                         | 完整方法的效果       |

### 注意事项

- A0 不能直接拿已有 P5SPFPrune（146 轮早停），要重跑 100ep
- A4 与 A5 同一计算图，只把热图监督损失权重设为 0
- A2 参数量可能超 A5，必须同时报告
- 胜出方案（相对 A0 有 +0.5 点以上、3 seeds 重叠少）进入 P4

## 条件路线（按前序结果决定）

### 无 P2 部署分支

**触发条件**: P0 显示 P2 路径在 Pi 5 上延迟占比>40%，且 P4 的 STP-SCA 有效。

**方案**: 先验接 backbone P2、FGDDown 迁移到 backbone P2→P3，保留便宜的 backbone P2 先验，逐步移除高成本的 P2 Neck 计算及 P2 Detect。

### 切片一致性

**触发条件**: P2 证明 Tile 独立增益明显、且 P4 的 STP-SCA 有效。

**方案**: "整图-切片一致性约束先验 logits"。

### 量化门控

**触发条件**: P4 的 INT8 测试显示门控路径比 baseline 掉点更多。

**方案**: 设计 QAT/混合精度。
