# 当前创新优先级（2026-10-16）

## 一句话主线

用一个受小目标监督的共享空间先验，统一约束 YOLO26 Neck 的跨尺度融合；用尺度适配器保留不同层的差异，并通过 Tile 因果对照和真实量化部署验证其有效边界。

> 本文件是当前开工入口。候选设计均为待验证假设；已登记历史结果见项目根目录 `研究重启_2026-09-25/01_实验登记表.csv`。

> 2026-10-16 执行校正：Tile960 缺同结构、非切片的已完成训练；本地 `yolo26/train_drone` 有 23 个 `best.pt`，此前搜索因默认忽略规则漏报。当前本机 Python 3.14 环境没有 torch，权重分析可在有依赖的 AutoDL 环境运行。仓库还有 4 个已修改代码文件和大量未跟踪实验文件，保存快照时只选择本项目明确需要的文件，不批量提交全部目录。

> **复杂度口径待修复**：旧消融表中的 YOLO26n、P2、P2+FGDDown 配置使用 `nc:80`，后续自定义 YAML 使用 `nc:10`；`P2+FGDDown → +DySample` 同时改了类别数与上采样，旧参数/FLOPs 差值不能归因于 DySample。先从各个已训练 `best.pt` 统一核对实际类别数，再分别统计未融合双头、融合后 o2o、最终导出后端实际图的参数和计算量；THOP 对 `grid_sample` 等非卷积算子的覆盖须明确，Pi 5 延迟是部署决策依据。同为 10 类的后半段行仍可作为探索性相对比较，但部署结论需重算。统一类别数后，P2 相对 baseline 的百分比可能增大或减小，不能预判方向。

## 优先级 1：STP-SCA 共享小目标先验

**工作名**：Supervised Tiny-object Prior with Scale-Calibrated Adapters。

**核心设计**：

- 从 backbone P2 预测单通道 prior logits；
- 用增强后的小目标 GT 软热图监督；
- 将 prior 对齐到当前三个 TGPFuse 融合点：P3、P2、P3；
- 在这三个融合点用每处最小仿射适配器校准先验 logits，再接 sigmoid；
- 若要声称覆盖 P4/P5 融合，须另做 P4 Concat/P5SPF 接入实验。P5SPFPrune 检测头只有 P2/P3/P4，没有 P5 检测头；
- 优先在 P5SPFPrune（无 TCA）上替换局部门控，并与原模型、P5SPFPrune+TCA_P3 做同预算比较，检验共享先验能否替代 TCA。

**为什么最值得投入**：

- 直接解决当前多个门控各学各的、解释割裂的问题；
- 能把模块堆叠改写为一个统一机制；
- 额外推理开销较小，并提供可视化热图；
- 与 Tile960 暗示的“小目标有效分辨率不足”问题一致。

**必须证明**：

1. 只加辅助监督但不门控，是否已经获得全部收益；
2. 共享先验是否优于每层独立受监督先验；
3. 尺度适配器是否优于直接复制同一门控图；
4. 是否改善 APsmall、密集区域 recall，而不只改善总体 mAP；
5. FP32/INT8 下先验和门控作用是否仍然存在。
6. 在原始 VisDrone 标注的 ignored regions 中屏蔽热图负损失；若原始标注不在训练环境中，先补齐或追踪转换来源。

**完整消融**：A0 原 P5SPFPrune；A1 监督 prior 但不门控；A2 独立受监督 prior 门控；A3 共享受监督 prior 门控但无适配；A4 共享不监督 prior + 适配；A5 共享受监督 prior + 适配。A4 与 A5 必须保持相同计算图，只将辅助热图损失权重设为 0，才能判断“监督”的贡献。A2 与 A5 应尽量对齐参数量及计算量，并报告实际差异。

**停止条件**：在同预算筛选中相对当前 TGPFuse3 没有稳定增益，或增益完全来自辅助 loss 而非共享门控，则不升级为主创新。

## 优先级 2：共享先验驱动的无 P2 检测部署分支

**前置条件**：统一重算复杂度并取得 Pi 5 上的 P2 路径延迟/内存数据，STP-SCA 在同预算对照中有效。

**目标**：保留 backbone P2 上轻量的先验预测和细节传递，逐步删除 P2 Neck C3k2 与 P2 Detect 路径，最终使用 P3/P4/P5 检测头。当前 FGDDown 与两处 TGPFuse 依赖 P2 Neck，不能直接删支路后称为同一模型；候选迁移方案是将先验接在 backbone P2、驱动 P3，并在同位置比较 backbone P2→P3 的 FGDDown。不能只删 P2 Detect 后就声称解决计算量。

**关键对照**：现有 P2 精度模型、简单去 P2 并重训、去 P2 + 共享先验、常规无 P2 YOLO26n。在相同数据和训练预算下比较 APsmall、统一口径 GFLOPs、峰值内存与 Pi 5 端到端延迟。历史 `+FGDDown` 数字只能作探索线索，不能替代迁移后模型的同预算对照。

**停止条件**：若先验补偿不了移除 P2 后的小目标精度损失，或 GFLOPs/真实延迟没有实质改善，则维持精度模型与独立部署模型两条路线，不把参数量下降写成推理加速。

## 优先级 3：共享先验上的切片—整图一致性

**前置条件**：先完成 Tile960 的同结构非切片训练，以及等优化步数对照；只有切片策略的独立作用和 STP-SCA 的作用都得到证实后才实施。

**改进方式**：对同一原图的整图视图和放大切片视图进行坐标对齐，约束 prior logits 或 GT 区域表征；不优先对整张 P2 特征做无掩码 L2。

**候选价值**：检验切片视图的监督信号能否改善整图推理；在完成同结构和等步数对照前，不把 Tile960 旧结果直接解释为尺度优势。

**风险**：SED、LG-RSD 等已有接近路线，新颖性中等偏低；必须与“只使用 Tile960 训练”直接比较，证明一致性损失有独立贡献。

**停止条件**：若不能显著优于单纯 Tile960，或训练成本接近翻倍但收益不稳定，则只保留为实验分析。

## 优先级 4：量化感知的门控保持

**前置诊断**：比较 baseline、当前最优模型和 STP-SCA 在 FP32/FP16/INT8 下的整体精度、APsmall、门控图相关性、分层 SQNR 和真实延迟。

**只有检测到明确退化后再做**：

- gate/sigmoid/mul 局部混合精度；
- 门控路径 QAT；
- 有界尺度系数或量化友好激活；
- 先验头与主干分层校准。

**价值**：与边缘部署题目直接一致，可形成方法的部署扩展或强实验章节。

**停止条件**：若候选模型的 INT8 相对掉点不高于 baseline，就不额外发明量化模块，直接把结果写成鲁棒性证据。

## 必须先完成的四项诊断

1. 门控审计：读取 gamma、统计实际调制量 `gamma × gate` 和 prior-GT 对齐度，再逐模块关断验证。gamma 接近 0 只说明门控残差弱；TCA/P5SPF 仍有卷积路径，关断掉点也会受下游协同适应影响；
2. o2o/o2m：同权重比较两条推理路径，并扫描 `max_det=300/500/1000`；分别记录完整 AP、按密度召回和前后处理延迟。该诊断无需训练，但仍需自训练 best.pt 和验证环境；
3. Tile 审计：目标尺寸、重复次数、空背景比例、类别权重及每 epoch 优化步数；补同结构原图训练和等总步数对照；
4. 导出冒烟：DySample/GridSample、共享先验和 Detect 在目标后端的兼容性。

正式训练前增设 **P0 复杂度重算**：逐一读取训练好的 `best.pt`，核对实际 `nc` 与检测层数；对 640/960 输入记录未融合双头、融合后 o2o 以及目标后端导出后的实际图。逐层分解至少覆盖 backbone、P2 Neck、其他 Neck、检测头；注明 THOP 的 MACs×2 约定和未统计算子。若 NCNN 实际导出使用 o2m+NMS，需独立报告该路径及后处理耗时。

## 暂缓方向

- P2 窗口稀疏计算：没有真实运行时或 kernel 时，乘掩码不会提速；
- 继续堆 TCA/注意力：已有边际收益下降和负结果；
- loss 小修、当前外部教师蒸馏、DMSSP：暂不占主算力；
- 把 o2o/o2m 对照包装成主创新：它更适合作为诊断和部署选择。
